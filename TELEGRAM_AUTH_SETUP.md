# 🤖 Настройка Telegram Авторизации

Подробное руководство по настройке авторизации через Telegram для Calendly MVP.

## 📋 Быстрый старт

### 1. Создание Telegram бота

1. **Откройте @BotFather** в Telegram
2. **Отправьте команду** `/newbot`
3. **Введите имя бота** (например: "Calendly MVP Bot")
4. **Введите username бота** (например: `calendly_mvp_bot`)
5. **Сохраните токен** - он понадобится для верификации (опционально)

### 2. Настройка домена

1. **В @BotFather отправьте** `/setdomain`
2. **Выберите вашего бота**
3. **Введите домен** (без https://): `calendly-mvp.vercel.app`

### 3. Настройка переменных окружения

#### В Vercel:
1. Откройте ваш проект в Vercel Dashboard
2. Перейдите в **Settings → Environment Variables**
3. Добавьте переменную:
   - **Name**: `NEXT_PUBLIC_TELEGRAM_BOT_USERNAME`
   - **Value**: `calendly_mvp_bot` (ваш username без @)
   - **Environment**: Production, Preview, Development

#### Локально (если используете):
```env
# .env.local
NEXT_PUBLIC_TELEGRAM_BOT_USERNAME=calendly_mvp_bot
```

### 4. Редеплой

1. **В Vercel** перейдите в **Deployments**
2. **Нажмите** "Redeploy" на последнем деплое
3. **Или** сделайте новый коммит в GitHub

## 🚨 Решение проблем

### Проблема: Виджет не появляется

**Симптомы:**
- Показывается "Telegram бот не настроен"
- Статус "Не настроено"

**Решение:**
1. Проверьте переменную `NEXT_PUBLIC_TELEGRAM_BOT_USERNAME` в Vercel
2. Убедитесь что имя бота правильное (без @)
3. Сделайте редеплой после добавления переменной

### Проблема: "Username invalid"

**Симптомы:**
- Виджет появляется, но показывает ошибку
- В консоли ошибка от Telegram

**Решение:**
1. Проверьте что бот создан в @BotFather
2. Убедитесь что username точно совпадает
3. Попробуйте создать нового бота с другим именем

### Проблема: "Bot domain invalid"

**Симптомы:**
- Виджет загружается, но авторизация не работает
- Telegram показывает ошибку домена

**Решение:**
1. В @BotFather: `/setdomain`
2. Выберите бота
3. Введите: `calendly-mvp.vercel.app` (без https://)
4. Подождите несколько минут для применения изменений

### Проблема: Авторизация не работает

**Симптомы:**
- Telegram окно открывается
- После авторизации ничего не происходит

**Решение:**
1. Откройте консоль браузера (F12)
2. Проверьте логи на наличие ошибок
3. Убедитесь что Supabase настроен правильно
4. Проверьте что домен настроен в @BotFather

## 🔧 Техническая информация

### Как работает авторизация

1. **Загрузка виджета** - Telegram скрипт создает кнопку авторизации
2. **Клик пользователя** - Открывается окно Telegram авторизации
3. **Callback функция** - Telegram возвращает данные пользователя
4. **Создание аккаунта** - Создается аккаунт в Supabase с email `telegram_{id}@telegram.local`
5. **Вход в систему** - Пользователь автоматически входит в дашборд

### Структура данных пользователя

```typescript
interface TelegramUser {
  id: number              // Уникальный ID Telegram
  first_name: string      // Имя
  last_name?: string      // Фамилия (опционально)
  username?: string       // Username (опционально)
  photo_url?: string      // URL аватара (опционально)
  auth_date: number       // Время авторизации (Unix timestamp)
  hash: string           // Хеш для верификации
}
```

### Безопасность

- **Email формат**: `telegram_{user_id}@telegram.local`
- **Пароль**: `telegram_{user_id}_{hash}` (уникальный для каждого пользователя)
- **Верификация**: Проверка обязательных полей и времени авторизации
- **Метаданные**: Данные Telegram сохраняются в профиле пользователя
