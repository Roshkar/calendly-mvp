## 🚀 Как использовать

### Создание события:
1. Перейдите на `/dashboard/event-types`
2. Нажмите "Создать событие"
3. Заполните форму:
   - **Название события** (обязательно)
   - **Описание** (опционально)
   - **Длительность** (обязательно)
   - **Место проведения** (опционально)
4. Нажмите "Создать событие"

### Просмотр событий:
1. Перейдите на `/dashboard/event-types`
2. Вы увидите все ваши созданные события
3. Можете копировать ссылки для бронирования
4. Можете удалять события

## 📝 Структура события

```javascript
{
  name: "Название события",
  slug: "auto-generated-slug",
  description: "Описание",
  duration_minutes: 30,
  location_type: "online|in_person|phone",
  location_details: "Zoom Meeting",
  color: "#3174ad",
  is_active: true
}
```

## 🔗 Ссылки для бронирования

Формат: `https://your-domain.com/book/[username]/[event-slug]`

Пример: `https://calendly-mvp.vercel.app/book/user/meeting-30min`

## ⚠️ Возможные проблемы

### 1. "Пользователь не авторизован"
**Решение:** Войдите в систему через `/login`

### 2. "Ошибка загрузки событий"
**Причины:**
- Неправильные переменные окружения Supabase
- Проблемы с RLS политиками
- Отсутствие таблиц в базе данных

**Решение:**
1. Проверьте `.env.local`:
   ```
   NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```
2. Выполните миграции: `supabase db reset`

### 3. "Ошибка создания события"
**Причины:**
- Дублирование slug
- Нарушение ограничений базы данных
- Отсутствие профиля пользователя

**Решение:**
1. Убедитесь, что пользователь имеет профиль в таблице `profiles`
2. Проверьте уникальность названий событий
